# Definition of Done
Dataset: checksums/schema/splits/preprocessor/label map/partition manifest/held-out manifest/leakage tests.
Model: tiny-batch overfit, checkpoint round-trip, deterministic inference, parameter count, calibration/OOD tests.
FL: FedAvg/MultiKrum/FedTrimmedAvg/proposed smoke runs, communication accounting.
Blockchain: 3-org network, both registries, replay/version/Merkle/endorsement tests.
RAG: source ingestion, MinIO, BGE-M3, Qdrant, RRF, hard provenance exclusion, retrieval benchmark.
OpenAI: sanitized schema, forbidden-field test, Structured Output parser, mock tests, explicit real-call gate, token/latency/cost logging.
Baselines: fidelity card, standard metric schema, smoke test, deviations documented.
Final experiments: five seeds completed or failures recorded; raw results immutable; plots/tables script-generated; paper claims trace to artifact IDs.
